# numpy<2 was originally pinned because faster-whisper / older librosa had
# ABI issues with numpy 2.0. With pyannote.audio 4.0 (and its scipy>=1.16,
# matplotlib>=3.10, lightning, torch 2.8 chain) the resolver wants
# numpy>=2 transitively — leaving <2 in place causes pip to backtrack
# through every numba version until it tries to build numba 0.56 from
# source (which guards against Python>=3.11 and crashes the build).
# Letting numpy go to 2.x is safe: torch 2.8, faster-whisper 1.1+,
# librosa 0.11, and pyannote 4 all advertise numpy 2 support.

# from the CPU index to keep the image slim. Declared here only for `pip install
# -r requirements.txt` use; the Docker build does the heavy work in two steps.

# `.speaker_diarization` (with overlap) and `.exclusive_speaker_diarization`
# (one-speaker-per-moment) annotations, plus `.speaker_embeddings` as a

# diarize.py for the migrated call site.
